III.1 En production

Agent IA · LLM local · RAG · MCP

Agent IA local de développement

Projet personnel · 2025 — 2026 · PACA

Assistant IA 100% local capable de comprendre une codebase complète, d'exécuter les tests, d'analyser l'historique git et de modifier le code de façon autonome — sans fuite de données vers le cloud.

Architecture du pipeline

Cœur agent
OpenCode (CLI / TUI) — orchestration LLM, MCP, contexte, diff & patches.
Cerveau
LLM local via Ollama — qwen2.5-coder:14b, variante :32b, fallback deepseek-coder-v2.
Mémoire
Index sémantique LanceDB + nomic-embed-text. Top-k au lieu de tout charger.
Couche d'action
MCP — serveurs filesystem, git, shell, search. Le LLM agit, ne se contente plus de répondre.
Sécurité
Policy layer (whitelist / blacklist), blocage rm -rf, sudo, git reset --hard, curl | sh.
Option PRO
Sourcegraph Cody, graphes de dépendances (madge / pydeps), agent autonome multi-étapes type OpenHands.

Cas d'usage

  • Onboardcompréhension d'un projet inconnu — fichiers pertinents, git, explication structurée
  • Refactorplan + édition + tests itératifs jusqu'à ce que tous les tests passent
  • Debuganalyse git diff / log sur régression, identification du commit suspect
  • Auditrevue de PR, signalement de risques, rapport généré

OpenCode · MCP (filesystem, git, shell) · Ollama · Qwen Coder · DeepSeek · LanceDB · nomic-embed-text · madge / pydeps · Docker Compose · Linux GPU

III.2 Opérationnel

Claude API · n8n · Automatisation

Générateur de lettres de motivation

Projet personnel · 2024 — 2025 · PACA

Pipeline complet pour produire des lettres de motivation personnalisées à partir d'une offre d'emploi : un formulaire web, un workflow n8n, l'API Claude. Suivi des candidatures dans un CSV permanent côté serveur et historique navigateur.

Pipeline

  1. 1 Frontend HTML / JS minimaliste — offre + sélection de profil (profils.json).
  2. 2 Webhook n8n → payload JSON (profil + offre).
  3. 3 Appel Claude Sonnet via HTTP Request (predefinedCredentialType: anthropicApi).
  4. 4 Injection dynamique des variables n8n dans le prompt.
  5. 5 Lettre retournée au navigateur + ligne CSV (Date, Entreprise, Objet, Type, Profil, Statut).

Résultats

  • < 5spar lettre générée et personnalisée
  • 0 manuelpipeline IA complètement automatisé
  • Modulaireajout de nouveaux profils sans toucher au code

HTML / JS vanilla · n8n (webhooks, HTTP Request, Write File) · Claude API (Anthropic) · MCP · JSON / CSV

III.3 En cours

LLM · TTS · Avatar · Pipeline GPU

TikTok AI Avatar Studio

Projet personnel · 2025 — 2026 · PACA

Application qui simule un Live TikTok entièrement piloté par IA : réception d'une question en temps réel → réponse LLM → voix → animation labiale de l'avatar → diffusion vidéo continue. Chaîne IA de bout en bout, optimisée GPU.

Pipeline temps réel

  1. 1 File FastAPI avec priorités (premium / normal), états pending → processing → completed.
  2. 2 Mistral-7B (HF Transformers) génère la réponse selon le profil actif.
  3. 3 Piper (fr_FR-mls-medium) synthétise la voix française naturelle.
  4. 4 SadTalker anime l'avatar en synchronisant les lèvres avec l'audio.
  5. 5 Flux intégré dans un master stream MP4 diffusé en boucle.

Détails techniques

  • Multi-profiljournaliste, chef cuisinier, vulgarisateur scientifique, etc.
  • ScrapingBeautifulSoup + feedparser (RSS / web) injectés dans le prompt
  • GPURTX 5060 Ti Blackwell sm_120, Docker Compose
  • DashboardHTML / JS — file en temps réel, ajout / reset

FastAPI · LangChain · Mistral 7B · HuggingFace Transformers · Piper · Bark · gTTS · SadTalker · LivePortrait · BeautifulSoup4 · feedparser · SQLite / PostgreSQL · n8n · Docker · GPU
